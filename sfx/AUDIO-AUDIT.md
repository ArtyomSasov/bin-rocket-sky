# Аудит звуков

Основные WAV в `sfx/` уже имеют в `CREDITS.txt` атрибуцию CC0 (Kenney, rubberduck, zer0sol).
Подтверждений, что они сгенерированы ИИ, в репозитории нет. Программный синтез Web Audio — отдельный
механизм: осцилляторы и шум создают звук на лету без модели ИИ.

## Что заменено

Твои оружейные файлы Quake и реплики диктора сохранены и имеют приоритет. Подключены переданные
`announcer_1stblood_01.mp3` и `flawless-victory-mk-x.mp3`.

| Событие | Новый готовый семпл |
| --- | --- |
| Подбор искр/звёзд | beep_01.ogg |
| Подтверждение убийства | terminal_05.ogg |
| Ступени заряда | terminal_02.ogg |
| Объявление без готовой реплики | teleport_01.ogg + текст |
| Акцент смерти / ядерного запуска | explosion_02.ogg |
| Гул двигателя (включается в настройках) | loop_machine_01.ogg |

Источник: [50 CC0 Sci-Fi SFX — rubberduck](https://opengameart.org/content/50-cc0-sci-fi-sfx).
Лицензия CC0. Оригиналы сохранены без перекодирования; высота и громкость меняются при воспроизведении.
Точные имена и ссылка на архив — в `pack/supplemental/CREDITS.txt`.
Chrome проверяет декодирование всех шести файлов, двух переданных реплик и запуск/остановку двигателя.
Проверка декодирования не заменяет прослушивание микса на колонках и телефоне.

## Что ещё синтезируется

- Низкочастотный удар под частью базовых выстрелов/взрывов (`SFX_TUNE`), поверх готовых файлов.
  На пользовательский Quake-пак эта обработка не накладывается.
- Импульс реверберации (`getHall`): процедурный хвост комнаты для базовых эффектов.
- Резервные короткие сигналы `blip`, шум взрыва `boomSound`, гул двигателя и аккорд объявления:
  используются, если нужный файл ещё не загрузился или не декодировался.
- Резервный хор святой гранаты; при доступном `holy-bomb.mp3` играет твой файл.

Браузерная озвучка `speechSynthesis` убрана. Для отсутствующих реплик не подставляется чужая по смыслу фраза:
остаётся короткий семпл и текст. Низ и реверберацию можно заменить записанными слоями, но это уже
изменит характер микса; их наличие само по себе не означает использование ИИ.
